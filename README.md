## Why Astro?

This site is built with [Astro](https://astro.build), a modern static site generator focused on:

- **Performance first**: Ships minimal JavaScript by default, resulting in lightning-fast load times
- **Content-driven**: Perfect for blogs and documentation with built-in content collections
- **Developer friendly**: Write components in your favorite framework or use plain HTML/Markdown
- **SEO optimized**: Automatic sitemap generation, RSS feeds, and Open Graph support
- **Zero JavaScript by default**: Only load JS when you actually need interactivity
