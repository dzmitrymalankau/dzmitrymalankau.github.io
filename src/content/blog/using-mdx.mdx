MDX is a special flavor of Markdown that supports embedded JavaScript & JSX syntax. This enables the ability to mix JavaScript and UI Components into Markdown content for things like interactive charts, alerts, and custom components.

## Capabilities

MDX unlocks powerful possibilities for content creation by allowing developers to embed interactive components directly within Markdown files. This is particularly useful for creating rich documentation, technical guides, and interactive tutorials.

## Example

Here is how you import and use a UI component inside of MDX.  
When you open this page in the browser, you should see the embedded component below.

import HeaderLink from '../../components/HeaderLink.astro';

<HeaderLink href="#" onclick="alert('Component activated!')">
	Embedded component in MDX
</HeaderLink>

## Integration Notes

MDX is configured in the `astro.config.mjs` config file. If you prefer not to use MDX, you can disable support by removing the integration from your configuration.

When using MDX in Astro, remember that Client Directives are still required to create interactive components. Otherwise, all components in your MDX will render as static HTML by default.
